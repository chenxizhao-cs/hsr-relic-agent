关于这次试用与评价口径

使用模拟账号，每次 +3 消耗 1 个演示步数；强化结果由你手动录入，不会操作游戏。Stop 表示对当前目标停止投入，不会弃置或分解遗器。独立打开地址创建独立试用会话，复制标签页可能继承同一会话。状态仅保留在服务内存中，重启服务后清空。

一轮强化，四个步骤

  1. 选择刃或希儿，查看推荐。
  2. 点击遗器卡片，查看评分、潜力与副属性。全部库存里也可以手动选择候选。
  3. 录入这一次新增的副属性或属性增量，例如暴击率增加 3.24 个百分点。
  4. 查看 Continue / Hold / Stop 的原因，继续当前件，或观察新的推荐。

想试试暂停流程？选择刃 → 全部库存 → 9100001，新增防御力% +5.4；之后再次选择它恢复观察，再录入防御力% +5.4。

这里录入的是模拟观察。已有四条词条时只能强化其中一条；只有三条时，需要新增第四条。
